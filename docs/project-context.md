# Contexto do projeto

O AutoFlow é um sistema para gerenciamento de oficinas automotivas.

## Tecnologias

- Java 21
- Spring Boot
- PostgreSQL
- Flyway
- Docker
- Angular

## Estrutura

- backend/
- frontend/
- infra/
- k8s/

## Restrições

- O backend deve seguir Clean Architecture.
- Controllers não devem conter regras de negócio.
- Use cases não devem depender do Spring.
